# Kho tài liệu nguồn

`Papers/` trong thư mục này dành cho bản PDF/tài liệu gốc được tải về để đọc và trích dẫn. Xem `AGENT_READ_PAPERS.md` trước khi xử lý tài liệu.

## Quy ước

- Lưu file gốc trong `Library/Papers/`; giữ nguyên nội dung sau khi tải về.
- Đặt tên dễ nhận diện: `FirstAuthor_Year_ShortTitle.pdf` (ví dụ `Hart_1992_NILM.pdf`).
- Không ghi chú, sửa PDF, đổi tên, di chuyển hay xóa file nguồn trong lúc đọc.
- Ghi metadata/thông tin trích dẫn và tổng hợp vào `Papers/` bên ngoài kho nguồn.
- Dùng `Papers/` để ghi bài báo; tạo liên kết tới file nguồn bằng đường dẫn tương đối nếu Obsidian hiển thị hỗ trợ, hoặc ghi tên file đầy đủ.

## Chỉ mục

Danh sách paper sẽ được tạo/cập nhật ở `Papers/README.md`. Giữ chỉ mục ở ngoài thư mục nguồn để thư mục này có thể được mount hoặc cấp quyền chỉ đọc cho agent.
